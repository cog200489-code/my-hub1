# 코스피 상위 50 분산 + 손절/반익절 전략 백테스트

- 기간: 2023-10-16 ~ 2026-10-15 (3년), 일별 종가, 원금 1억
- 종목: 2023년 10월 시총 상위 50 (우선주 제외, 근사)
- 규칙: 동일비중 매수 → 평단 대비 -10% 전량 손절 / +20% 절반 익절 → 익절 종목은 91일간 매도 금지 → 매도금은 50종목에 다시 균등 매수 (소수점)
- 익절 후 기준가는 익절가로 재설정 (원래 평단 유지 버전도 비교)
- 비용: 매수 0.015%, 매도 0.195% (수수료+거래세)
- 데이터: 구글 시트 GOOGLEFINANCE (`prices.csv`), 배당 미포함

실행: `python3 backtest.py` → `equity.csv`(자산 곡선), `trades.csv`(매매 기록)
