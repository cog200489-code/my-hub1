# 코스피 상위 50 분산 + 손절/반익절 전략 백테스트

- 기간: 2023-10-16 ~ 2026-10-15 (3년), 일별 종가, 원금 1억
- 종목: 2023년 10월 시총 상위 50 (우선주 제외, 근사)
- 규칙: 동일비중 매수 → 평단 대비 -10% 전량 손절 / +20% 절반 익절 → 익절 종목은 91일간 매도 금지 → 매도금은 50종목에 다시 균등 매수 (소수점)
- 익절 후 기준가는 익절가로 재설정 (원래 평단 유지 버전도 비교)
- 비용: 매수 0.015%, 매도 0.195% (수수료+거래세)
- 데이터: 구글 시트 GOOGLEFINANCE (`prices.csv`), 배당 미포함

실행: `python3 backtest.py` → `equity.csv`(자산 곡선), `trades.csv`(매매 기록)

## 규칙 조합 비교 (`python3 grid.py`)
앞 1.5년·뒤 1.5년을 따로 돌려 운으로 맞은 조합인지 점검.

(원안 +138%/-28%, 그냥 보유 +161%/-35%, KODEX200 +192%/-40%)

## 하락장 검증 (`python3 bear.py`, 데이터 `prices_2021.csv`, 종목 `tickers_2021.py`)
2021-07 시총 상위 50으로 2021-07 ~ 2022-09 하락장과 2021-07 ~ 2024-06 3년을 다시 돌림. 결과는 `bear_result.txt`.
- 개선안은 하락장에서 그냥 보유와 똑같이 -31% → 손절해도 판 돈을 바로 다시 사서 방어가 안 됨
- 보완안(KODEX200이 120일선 아래면 판 돈을 현금으로 대기): 하락장 -21%로 덜 잃지만, 3년 전체로는 이득 없음
- 결론: 이 규칙들은 시장을 이기는 힘(우위)이 없음. 수익은 대부분 시장 덕
